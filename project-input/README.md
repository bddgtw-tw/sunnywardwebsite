# Sunnyward Project Input

這是案例原始資料的私有人工投放區，不會被匯出到公開網站。

每個案例固定使用以下結構：

```text
project-input/<project-slug>/
├─ text/    原始文案、補充說明或需求文件
├─ images/  原始照片
└─ video/   原始影片
```

人工只需要把素材放入對應資料夾。公開命名、三語文案、manifest、HTML、SEO、媒體整理與發布檢查由 AI 處理。

請勿將報價、供應商、FOB、成本、毛利或其他內部採購資料放入公開 `projects/`；若原始文件包含這些資訊，必須先由 AI 清理後才能進入公開輸出。
