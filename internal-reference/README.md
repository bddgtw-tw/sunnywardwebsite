# Sunnyward internal reference

此區保存供人員與 AI 使用的內部策略參考，不是網站前台內容，也不得匯出至公開部署。

## 使用方式

1. 先讀取 `brand/sunnyward-enterprise-dna.json`，理解品牌定位、語氣、證據邊界與判斷原則。
2. 處理個別案例時，再讀取 `project-input/<project-slug>/text/strategy.json`。
3. `confirmed` 只代表現有媒體與紀錄支持的內容。
4. `inferred_for_internal_planning` 是工作假設，不得當成真實業主說法或完成成果。
5. 未來取得核准的 brief、規格、數量、訪談或成果後，應優先用正式資料取代推論。

## 公開邊界

- `internal-reference/`：永不公開。
- `project-input/`：原始資料與內部策略，永不公開。
- `projects/` 與三語 HTML：經過處理後的公開內容；仍須通過發布檢查。
